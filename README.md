<h2>GPT Projects</h2>

<p>Welcome to GPT-Projects, a collection of experiments, tools, and applications built using OpenAI's ChatGPT. With the rise of advanced AI models, ChatGPT enables users to go beyond conversations — allowing the creation of Custom GPTs tailored for specific tasks, services, or industries.</p>

<p>These projects showcase the potential of AI-powered assistants to integrate external APIs, provide dynamic responses, and assist users in unique ways.</p>

<h3>What is a Custom GPT?</h3>

<p>Custom GPTs are personalized versions of ChatGPT that can:
<ol type='1'>
    <li>Follow specific instructions,</li>
    <li>Access uploaded files or tools,</li>
    <li>Call external APIs,</li>
    <li>Call external APIs,</li>
</ol>

<p>Respond with domain-specific knowledge or behavior.

Creating a Custom GPT does not require programming skills — OpenAI provides a simple interface to guide you through the process</p>

<h3>Prerequisites</h3>

Before creating Custom GPTs, ensure you have the following:
<ol type="1">
    <li>✅ An OpenAI account.</li>
    <li>⭐ An active ChatGPT Plus subscription (required to access GPT-4 and the Custom GPT builder).</li>
    <li>🌐 Basic idea or goal for your GPT (e.g., a nutrition checker, tutor, assistant, etc.).</li>
    <li>🚀 How to Create a Custom GPT (Quick Steps)
        <ol type="a">
            <li>Go to chat.openai.com and log in.</li>
            <li>Click on Explore GPTs or the Create button.</li>
            <li>Use the GPT Builder to:
                <ol type="i">
                    <li>Name your assistant.</li>
                    <li>Set instructions and goals.</li>
                    <li>Optionally upload files or API keys.</li>
                    <li>Test and publish your GPT.</li>
                    <li>Once saved, it can be shared via a public link or accessed only by you.</li>
                </ol>
            </li>
        </ol>
    </li>
</ol>
